## PL

### Instrukcja instalacji pierwszego komputera agentów

Powstała instrukcja krok po kroku i skrypt pierwszych kroków dla laptopa, który ma się stać komputerem agentów: Fedora 45 z szyfrowaniem całego dysku, włączony Secure Boot, automatyczne aktualizacje bezpieczeństwa, zapora, która niczego nie udostępnia, i raport z instalacji bez haseł. Odblokowanie dysku przez układ TPM jest opcjonalne i wymaga zapisania klucza odzyskiwania. Skrypt przeszedł kontrolę składni, ale nie był jeszcze uruchomiony na Fedorze; instalacja jest przed nami.

## EN

### Installation guide for the first agents' computer

We prepared a step-by-step guide and a first-steps script for the laptop that is to become the agents' computer: Fedora 45 with full-disk encryption, Secure Boot on, automatic security updates, a firewall that exposes nothing, and an installation report without passwords. Unlocking the disk with the TPM chip is optional and requires writing down a recovery key. The script passed a syntax check but has not yet run on Fedora; the installation is still ahead.
