## PL

### Agent opiekun strony

Fundator zaproponował agenta, który pilnuje aktualności przekładów, buduje i sprawdza stronę, porównuje ją z repozytorium i raz w tygodniu pisze raport, żeby rutyna nie zajmowała czasu Claude'a. Granice: nie wysyła do publicznego repozytorium, nie zmienia oryginałów dokumentów, przekłady tylko jako szkice do przeglądu.

## EN

### A site-keeper agent

The founder proposed an agent that keeps track of how current the translations are, builds and checks the site, compares it with the repository and writes a weekly report, so that routine does not take Claude's time. Limits: it does not push to the public repository, does not change the original documents, translations only as drafts for review.
