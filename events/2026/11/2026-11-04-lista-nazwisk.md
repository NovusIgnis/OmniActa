## PL

### Prywatna lista nazwisk poza repozytorium

Na uwagę fundatora lista nazwisk osób spoza fundacji, którą narzędzie akt wyłapuje przed publikacją, nie jest już jawnym plikiem przy repozytorium. Leży poza repozytoriami, zaszyfrowana kluczem konta systemu fundatora, a publiczny kod i README nie podają jej nazwy ani miejsca. Szyfrowanie chroni listę przy kopiowaniu dysku albo kopii zapasowej, ale nie przed programem działającym na koncie fundatora.

## EN

### The private list of names outside the repository

Following the founder's remark, the list of names of people outside the foundation, which the records tool catches before publication, is no longer a plain file next to the repository. It is kept outside the repositories, encrypted with the key of the founder's system account, and the public code and README name neither the file nor its location. Encryption protects the list when the disk or a backup is copied, but not from a program running under the founder's account.
