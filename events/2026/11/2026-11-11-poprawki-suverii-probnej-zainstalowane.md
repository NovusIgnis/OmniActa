## PL

### Poprawki Suverii próbnej zainstalowane

11 listopada 2026 o 13:03 fundator zainstalował na komputerze agentów poprawki Suverii próbnej, o których zdecydował tego ranka. Wystarczyło jedno polecenie z hasłem administratora. Skrypt najpierw zrobił świeżą, zablokowaną kopię kontenera w stanie sprzed zmiany kodu. Potem porównał sumy kontrolne kodu z sumami po przeglądach i uruchomił testy programu próbnego i bramy. Dopiero gdy wszystko się zgodziło, przełączył bramę i stronę na nowe wersje. Poprzednie wersje zostały obok, żeby można było do nich wrócić. Od tej chwili odpowiedź modelu może mieć do 4096 tokenów zamiast 512, a ucięcie jest widoczne na stronie. Przy wypowiedziach widać godzinę. Gdy nie wiadomo, czy dostawca odpowiedział, strona pisze „wynik nieznany”. Karta ochrony ma akapit „Pamięć” w zatwierdzonym brzmieniu, a brama czeka na odpowiedź najwyżej 230 sekund. Sprawdzenie po instalacji objęło tylko stan usług, wersje i to, czy strona odpowiada. Agenci nie otwierali kontenera i nie czytali rozmów, więc działania poprawek z prawdziwym dostawcą modelu nikt z nich nie sprawdzał.

## EN

### Fixes to the trial Suveria installed

On 11 November 2026 at 13:03 the founder installed, on the agents' computer, the fixes to the trial Suveria that he had decided on that morning. One command with the administrator password was enough. The script first made a fresh, locked copy of the container in its state from before the code change. It then compared the checksums of the code with the checksums from the reviews and ran the tests of the trial program and of the gateway. Only when everything matched did it switch the gateway and the page to the new versions. The previous versions stayed alongside, so that it is possible to return to them. From then on a model answer can be up to 4096 tokens instead of 512, and a cut-off is shown on the page. Each message shows its time. When it is not known whether the provider answered, the page says "result unknown". The protection card has the "Memory" paragraph in its approved wording, and the gateway waits for an answer for at most 230 seconds. The check after installation covered only the state of the services, the versions and whether the page responds. The agents did not open the container and did not read the conversations, so none of them checked how the fixes work with the real model provider.
