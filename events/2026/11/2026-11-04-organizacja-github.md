## PL

### Repozytoria fundacji w organizacji NovusIgnis

Przy zakładaniu aplikacji dla formularza OmniVox okazało się, że NovusIgnis na GitHubie to konto osobiste, nie organizacja. GitHub nie pozwala już zamienić konta osobistego w organizację, więc fundator założył organizację NovusIgnis jako należącą do instytucji, Fundacji Novus Ignis, przeniósł do niej pięć publicznych repozytoriów (NovusIgnis.org, OmniActa, OmniArca, Suveria, OmniVox) i zmienił nazwę dawnego konta na SalveNovusIgnis. To konto jest właścicielem organizacji. Adresy repozytoriów się nie zmieniły. Wysyłanie zmian, ustawienia wgrywania strony i samo wgrywanie działają jak przedtem; sprawdziliśmy to przy wieczornych wgraniach. Dyskusje organizacji są włączone i prowadzą do OmniVox. Otwarte: czy organizacja dostanie drugiego właściciela i czy zarząd zapisze, kto nią zarządza.

## EN

### The foundation's repositories in the NovusIgnis organisation

While setting up the app for the OmniVox form, it turned out that NovusIgnis on GitHub was a personal account, not an organisation. GitHub no longer allows converting a personal account into an organisation, so the founder created the NovusIgnis organisation as belonging to an institution, Fundacja Novus Ignis, moved five public repositories into it (NovusIgnis.org, OmniActa, OmniArca, Suveria, OmniVox) and renamed the former account to SalveNovusIgnis. That account owns the organisation. The repository addresses did not change. Pushing changes, the website deployment settings and the deployment itself work as before; we checked this during the evening deployments. The organisation's discussions are enabled and lead to OmniVox. Open: whether the organisation gets a second owner and whether the board records who manages it.
