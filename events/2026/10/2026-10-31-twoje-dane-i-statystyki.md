## PL

### Informacja o danych i jawne statystyki strony

**Cel:** odwiedzający wie, co strona o nim zbiera i po co.

**Warianty:** nie ustalono.

**Kogo dotyczy:** odwiedzających stronę i osoby zapisane na listę oczekujących.

**Wykonanie:** strona „Twoje dane” mówi, że adres z listy oczekujących posłuży tylko do jednej wiadomości o starcie prób, a potem zostanie usunięty. Skrypt statystyk liczy z dzienników serwera tylko zbiorcze liczby, bez adresów IP i opisów przeglądarek, a publiczna strona statystyk mówi, co zbieramy (zmiany w kodzie 11:31–11:59). Najtańszy pakiet hostingu nie daje dzienników serwera; dostęp do nich Claude sprawdzał w dokumentacji dostawcy.

## EN

### Information about data, and open site statistics

**Goal:** visitors know what the site collects about them and why.

**Options:** not established.

**Who it affects:** visitors to the site and people signed up for the waiting list.

**Execution:** the “Your data” page says that an address from the waiting list will be used only for one message about the start of the trials and then deleted. The statistics script counts only aggregate numbers from the server logs, without IP addresses or browser descriptions, and a public statistics page says what we collect (code changes 11:31–11:59). The cheapest hosting package provides no server logs; Claude checked access to them in the provider's documentation.
